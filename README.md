# 剑指OFFER · AI求职工具站（前端复刻演示）

> AI出鞘，直指Offer。本站是对某「AI求职工具集合站」的**布局与功能复刻学习项目**：
> 品牌名、文案、视觉、代码全部为原创实现，与原站无任何关联；无会员/付费功能。

## 运行方式

纯静态站点，零依赖、零构建。二选一：

```bash
# 方式一：直接双击 index.html（部分浏览器对 file:// 限制 fetch，推荐方式二）
# 方式二：本地起服务
cd jianzhi-offer
python -m http.server 8137
# 打开 http://127.0.0.1:8137
```

### 使用插件在真实网申页自动填写

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）→ 开启「开发者模式」→「加载已解压的扩展程序」→ 选择 `extension/` 文件夹
2. 回到演示站「AI填网申」页刷新一次，标题旁出现「🟢 已连接插件」即代表自动同步已接通；此后保存资料库、学习新字段都会实时同步到插件
3. 打开任意企业招聘官网的网申页 → 点 ⚔️ →「⚡ 填写本页表单」→ 检查并补填列出的缺失字段
4. 手动修正后点「🧠 学习本页修改」→ 修正写回资料库，下次自动带上

同步机制：插件向演示站页面注入 bridge.js 桥接脚本，双方通过 postMessage 通信读写插件存储（带 updatedAt 时间戳合并，学习字段按并集合并）。「导出JSON」仅作为插件未连接时的备用方案保留。

安全说明：插件不自动勾选任何同意条款；数据仅存本地（站点 localStorage / 插件 chrome.storage）；提交前请人工检查。

## AI 双轨说明

- **本地规则引擎（默认，开箱即用）**：技能词库（150+中英词条）、TF关键词提取、动词升级、STAR重组、量化提醒、JD命中率算法。全部在浏览器内完成，不上传任何数据。
- **大模型API（可选）**：右上角 ⚙️ 设置 → 填入 OpenAI 兼容的 Base URL / Key / 模型名 → 简历魔改自动切换为真AI，失败自动回退规则引擎。

## 岗位数据源

- 默认 [Arbeitnow](https://www.arbeitnow.com/api/job-board-api)（免费公开、CORS开放、真实在招岗位）
- 可切换 [Remotive](https://remotive.com/api/jobs)（同上）
- 可自定义端点：返回 `[{"title","company","location","tags","url","description"}]` 即可接入国内岗位API

## 数据与隐私

登录（演示）、资料库、表格、简历编辑器内容全部存储在浏览器 `localStorage`，不含任何后端与上传。
